# Claims for D5

Establishes: over a long decode, whether (1) the regularized key-matrix condition
stays below the configured bound and (2) reconstruction shrinks. For C4 the gating
shrinkage is the generated-token window (W1); for C3 it is the full-window memory
shrinkage. The other window is reported as a diagnostic.

Does not establish: distribution equivalence, long-text task accuracy, or a learned
memory representation.
